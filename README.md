Prima architettura di CODEX!, pensata per essere ampliata con nuovi moduli.


## Convenzione moduli CODEX!

Ogni codice o sistema aggiunto a CODEX! deve prevedere due schede informative distinte:
- **? COME FUNZIONA** — regole, funzionamento e uso del modulo.
- **◷ STORIA** — brevissimo contesto storico: quando nasce, autore/origine quando nota, e in quale contesto veniva o viene utilizzato.

**COME FUNZIONA + STORIA** è la convenzione obbligatoria per tutti i futuri moduli di CODEX!.
